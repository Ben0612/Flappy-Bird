# Flappy Bird - Reinforcement Learning

使用 Python 與 Pygame 開發的 Flappy Bird 遊戲專案。

本專案從基礎遊戲開始，逐步加入隨機水管、遊戲環境與強化學習，最終希望讓 AI 能夠自行學習並遊玩 Flappy Bird。

---

## 📌 Project Overview

本專案主要分為兩個部分：

1. **Flappy Bird 遊戲開發**
2. **強化學習 AI 開發**

目前先完成遊戲本體，後續將加入 Q-Learning 與 DQN。

## 🎯 Project Goal

本專案希望透過實際製作遊戲，學習：

* Python 程式設計
* Pygame 遊戲開發
* Git / GitHub 版本控制
* 強化學習
* Q-Learning
* Deep Q-Network (DQN)
* AI 模型訓練

最終讓 AI 能夠根據遊戲環境，自行判斷是否讓小鳥飛行，並透過訓練逐漸提高遊戲表現。
